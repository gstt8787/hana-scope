# HANA Scope

スマート沖スロ スターハナハナ（スターハナハナ-30）の設定推測とシミュレーションを、端末の中だけで計算するWebアプリです。
外部サーバーへの送信、外部API、広告、アクセス解析は使用していません。入力内容はブラウザーのローカルストレージにのみ保存されます。

**公開URL: https://gstt8787.github.io/hana-scope/**

## iPhoneでの使い方

1. Safariで上記URLを開く。
2. 画面下の共有ボタン → 「ホーム画面に追加」を選ぶ。
3. ホーム画面のアイコンから全画面で起動する。一度開いたあとは、電波が届かない場所でも起動できます。

## 画面

### 設定推測

- 台データ（総ゲーム・BIG・REG）を入力すると、設定1〜6への当てはまりを表示します。
- 着席後に自分で確認した示唆を、ボタンのタップで記録できます。
  - 見たBIG回数と、BIG中のスイカ回数（サイドランプが赤緑にフラッシュした時に狙って揃うスイカ）
  - 見たREG回数と、REG中サイドランプの色（左リール中段に白7をビタ押ししてスイカが揃った時の色）
  - フェザーランプの色（BIG後・REG後。白以外が光った時のみ）
- 「設定4以上」「設定5以上」「設定6」の確率と、要素ごとにどの設定へ傾いているかを表示します。
- REG後のフェザーランプなど、特定設定以上が濃厚とされる示唆が出た設定以外は「否定」として除外します。
- 「解析サイトの数値も使う」を外すと、メーカー公表のボーナス確率だけで計算します。

### シミュレーション

- 設定1〜6を同じゲーム数・試行回数・乱数シードでモンテカルロ試行します。
- 平均差枚、金額換算、BIG/REG平均、勝率と95%信頼区間、最終差枚の10〜90%範囲を表示します。
- 代表試行のスランプグラフ、最高差枚、最大ハマリ、最大ドローダウン、全当選回転数を確認でき、当選履歴をCSVで保存できます。

## 数値の扱い

- BIG・REG確率、払出枚数、出玉率はメーカー公式の公表値を使用しています。
- 設定示唆（BIG中スイカ確率、REG中サイドランプ色、フェザーランプ色）の振り分けはメーカー非公表のため、解析サイトの掲載値を使用し、画面上で非公式と明示しています。実機の仕様と異なる可能性があります。
- 通常時のベル確率とレトロサウンドは、情報源によって数値が食い違うため推測に使用していません。
- 各ゲームは独立抽選として計算しています。連チャンモードや波などの未公表仕様は仮定していません。

結果は将来の出玉の予測ではなく、指定した確率モデルのもとでのデータの当てはまりとブレ幅です。設定を確定することはできません。
